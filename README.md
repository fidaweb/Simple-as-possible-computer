# Simple As Possible (SAP) Computer

A simple 8-bit computer project built and simulated with **Logisim Evolution**.

## Open the Project

1. Install [Logisim Evolution](https://github.com/logisim-evolution/logisim-evolution).
2. Open `SAP_Computer.circ` in Logisim Evolution.
3. Select the `Main1` circuit to view the main computer.

## Main Parts

- **Program Counter** – keeps track of the program address.
- **RAM** – stores program instructions and data.
- **Input MAR** – holds the memory address.
- **Instruction Register** – holds the current instruction.
- **Control Unit** – controls the computer's operations.
- **Accumulator** – stores calculation results.
- **B Register** – holds a second value for calculations.
- **Adder/Subtractor** – performs addition and subtraction.
- **Output Register** – holds data for output.
- **Step Counter** – tracks the control steps.
- **Display** – shows output values.

## Project File

- `SAP_Computer.circ` – the Logisim Evolution circuit file.

## Notes

Compatible with Logisim Evolution **3.8.0** . It may also open in newer versions.
